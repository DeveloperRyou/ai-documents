# e2e 필수 (TCTP)

- 이슈를 해결하거나 동작이 바뀌는 코드 변경을 할 때마다 e2e 를 같은 커밋에 추가한다. 단위 테스트만으로는 끝나지 않는다.
- 이 프로젝트의 e2e = 드릴: `packages/sim/src/drills.ts` 에 더하면 `packages/tools/src/drills.test.ts` 가 `npm run check` 에서 전부 돌리고, `?debug=drills` 로 틱 단위 재생해 볼 수 있다.
- 고친 동작마다 정상 경로 드릴 하나, 예외(그치는 조건·거부되는 조건·한계)마다 드릴 하나. 기대 결과는 드릴 `title`·`desc` 에 쉬운 말로 적는다.
- 동작이 바뀌지 않는 변경(문서, 이름 바꾸기, 순수 리팩터, 확인장 UI 표시만)은 예외다. 그때는 최종 보고에 "e2e 해당 없음 — 이유" 한 줄을 남긴다.
