# 조사 근거 모으기 (TCTP)

수치·식·편제·교범 절차를 바꾸려고 조사한 내용은 `docs/research/` 에 남긴다. 다음 세션이 같은 검색을 되풀이하지 않게 하고, `docs/calc` 의 출처 줄이 가리킬 곳을 만든다.

- **파일**: 이슈 하나에 파일 하나, `docs/research/<이슈번호>-<주제>.md`. 이슈가 없는 조사는 `<주제>.md`. 새 파일은 [`docs/research/README.md`](../../docs/research/README.md) 목록에 한 줄을 더한다.
- **항목마다 등급**을 붙인다.
  - `확인`: 1차 출처(교범 원문·연구 보고서·논문 본문)를 직접 열어 그 숫자를 봤다.
  - `2차`: 위키·블로그·요약·재인용에서 봤고, 원문은 아직 못 열었다. 원문 서지를 함께 적는다.
  - `추정`: 출처 없이 고른 값이다. 왜 그렇게 골랐는지 적는다.
  - 검색 요약만 보고 쓴 숫자는 `확인`이 아니다.
- **적을 것**: 숫자·식(단위 포함), 출처 링크, 서지(저자·연도·기관), 조건(사거리·자세·부하 등 그 숫자가 성립하는 전제), 접근 실패(예: DTIC 403)와 다음에 볼 곳.
- **반영**: 수치는 `확인` 또는 사용자가 승인한 `2차`만 코드에 넣는다. 넣으면 `docs/calc/<문서>.md` 출처 줄이 이 파일을 가리키게 하고, 이 파일의 "반영" 칸에 커밋을 적는다 ([calc.md](calc.md) 절차).
- **이슈**: 조사를 마치면 이슈에 이 파일 링크와 남은 공백을 한 줄로 코멘트한다. 근거가 모자라면 `design:needs-research` 를 유지한다.
