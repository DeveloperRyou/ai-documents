# POC 기록 (종료)

실 개발 전에 만든 POC 두 개의 경위와 결과. 코드는 `poc/` 에 보관만 하며 실 개발에서 import 하지 않는다.
폴더별 실행 방법·git 태그는 [`poc/README.md`](../poc/README.md).

## 경위
- `poc/battalion` — 대대~연대급 지휘통제실(TOC) 워게임. 명령 지연·보고 기반. 분대~소대 직접 조작 전술 시뮬로 피봇하며 종료 (2026-10-14).
  여단 과정에서 이 명령 지연·보고 모델을 다시 쓸 예정.
- `poc/squad` — 분대~소대 직접 조작 전술 시뮬. 실제 지도(독일 라스도르프), 공통 Soldier 객체. 종료 (2026-10-15).
  - 체크포인트 1 (`squad-checkpoint-1`): 분대장 지휘 미니 시나리오 `mg-nest` (분대 9 vs 기관총 진지 6). 사용자 평가 "확실히 재미는 있네".
  - 체크포인트 2 (`squad-checkpoint-2`): 소대장 지휘 실험 (분대에 임무를 주고 분대장 AI 가 수행, `platoon-attack`). 돌아가긴 했으나
    임무 AI·경유점·지원 위치 선정 등 구현할 것이 많아 첫 제품은 분대장 지휘로 정함.
- `poc/opfor-llm` — 크롬 내장 LLM 이 대항군을 지휘하는 실험 (2026-10-15). 아래 "LLM 대항군".
- `poc/plans` — 대대 POC 시절 기획·개선안 문서 (P-001~006).

## 검증 수치 (headless, mg-nest 30판)
- 지원 위치 제압 → 15m 에서 사격 전환 → 돌입: 16승 / 제압 없이: 9승 / 전원 정면 돌격: 0~1승.
- 사격 전환을 35m 에서 하면 제압 효과가 사라진다 (적 회복 ~10초).

## POC 의 한계와 실 개발에서 바꾼 것
- POC 는 명령 함수가 상태를 바로 바꿔 리플레이가 불가능했고, 사후검토는 1초 프레임 녹화에 의존했다 → 명령을 데이터(`Command`)로, 틱 경계에서 적용.
- 시간이 부동소수 `t` 의 반올림이었다 → 정수 틱.
- 시뮬·DOM·Node 코드가 섞여 있었다 → 패키지 분리.
- 경로 탐색이 적 시야를 몰라 노출된 길로 갔다 → 경유점 지정이 열린 질문으로 남음.
- 지점 제압은 사격 통제 순환으로만 해제됐다 → 전용 취소·전환 조작이 열린 질문으로 남음.

## LLM 대항군 (`poc/opfor-llm`)
결론: **게임 안 대항군 AI 를 브라우저 내장 LLM 으로 돌리는 것은 가능하다.** 서버·API 키 없이 기기 안에서 돌고, 기존 구조(정보 안개 `Snapshot` → `Command`) 그대로 붙는다.

- 구조: 대항군 진영 `Snapshot` 을 영어 상황 보고로 → Prompt API(`responseConstraint` JSON 스키마) → 조별 명령 → `session.issue`. 응답은 비결정적이지만 `commandLog` 에 쌓이므로 리플레이·`stateHash` 결정성은 유지된다 (AI 출력 = 명령 기록).
- 실기 (크롬 155 Windows, Gemini Nano, `#prompt-api` 플래그): 7턴 모두 스키마에 맞는 JSON. 지연 2.8~4.0초 → 6초 결정 주기 안에 든다. 실시간 개인 조작은 무리, **조·분대 수준 수 초 단위 결정**에 맞다.
- 판단: 적 6명이 210~250m 에 보일 때 "100m 안까지 은폐 유지 후 고착" 매복 의도 — 임무 설명에 맞음.
- 한계 (소형 모델):
  - 방위·거리를 직접 계산하지 못하고 상황 보고의 숫자를 따라 쓴다 (정지 명령에 조 위치 방위를 그대로, 2조를 적 반대쪽 4° 로 이동).
  - 직전 의도를 다시 넣으면 문장이 불어나 길이 제한에서 잘린다.
  - 지형(엄폐·건물)을 모른다. 상황 보고에 넣지 않았다.
- 실 개발로 옮길 때 할 것: 모델에게는 전술 동작만 고르게 하고(`hold`·`advance`·`flank_left/right`·`withdraw`) 좌표는 코드가 계산, 의도는 짧은 한 문장·누적 금지, 같은 방향 적은 묶어서 보고, 결정적 샘플링(`temperature:0` 등). 크롬 외 브라우저·모델 없는 기기용 규칙 기반 대체 AI 필요.
