# 설계 메모 — POC 에서 가져온 결정과 열린 질문

POC 두 개(`poc/battalion` 대대 지통실, `poc/squad` 분대·소대 전술)를 거쳐 정한 것. 실 개발은 이 문서를 기준으로 시작한다.

## 방향
- 제목 **TCTP — Tactical Command Training Program** (2026-10-15). MCTP·BCTP 식 전투지휘훈련 게임.
  가상의 훈련 과정이며 실제 프로그램(MCTP·BCTP, 전투지휘훈련단) 이름·휘장은 쓰지 않는다.
- 과정 사다리: 분대·소대(직접 지휘) → 중대·대대(임무 부여, 하급 제대 AI 수행) → 여단(지휘소에서 보고·명령).
  여단 과정에서는 `poc/battalion` 의 명령 지연·보고 모델이 다시 쓰인다. 훈련 요소 = 실제 지도 훈련장, 같은 규칙의 대항군, 사후검토.
- 대대급 지통실(명령 지연, 보고 기반) → **분대~소대 직접 조작 전술 시뮬**로 피봇 (2026-10-14).
- 첫 제품은 **분대장 지휘**. 소대장 지휘(분대에 임무를 주고 분대장 AI 가 수행)는 POC 에서 돌아가긴 했으나
  임무 AI·경유점·지원 위치 선정 등 구현할 것이 많아 이후 단계로 미룬다 (2026-10-15).
- 재미가 확인된 핵심: 분대장이 **지점 제압 → 기동 → 사격 전환 타이밍 → 돌입**을 직접 판단하는 것.
  POC 미니 시나리오 `mg-nest`(분대 9 vs 기관총 진지 6)에서 사용자 평가 "확실히 재미는 있네".

## 시뮬 모델 (POC `poc/squad/sim` 참고, 옮겨 오며 다듬을 것)
| 영역 | POC 에서 정한 것 | POC 파일 |
|---|---|---|
| 지형 | OSM 벡터 → 1m 격자 (밀도·은폐·엄폐·통행), 고도 4m 격자 쌍선형, 고도 시선·능선 엄폐 | `terrain.ts` |
| 이동 | 2m A* + 경사 비용, 사람 간 최소 1m, 낮은 자세 걷기 ×0.8 · 포복 ×0.6 | `pathfind.ts`, `movement.ts` |
| 시야 | 양안 120° 온전, 주변 200° 까지 감소, 그 밖은 총성만 | `detection.ts` |
| 사격 | 부위별 부상·방호구 내구도·폭발, 사격 품질(걷기·제압 시 저하) | `combat.ts` |
| 제압 | 받는 제압 ×= 기본 + 엄폐 계수 × (발밑·사격 방향 시선 엄폐 중 작은 값). 이동 중 ×1.15 | `combat.ts`, `condition.ts` |
| 지점 제압 | 지점 주변 12m 를 쓸어 쏨, 진지 안 적 전원 제압, 직격 드묾 | `orders.ts`, `combat.ts` |
| 상태 | 제압·사기·출혈·수분·응급처치(구급품 소모) | `condition.ts` |
| 장비·자원 | 탄약, 수류탄·유탄, 붕대·지혈대, 수통, 방탄모·방탄복 내구도, 쌍안경·무전기, 하중 | `soldier.ts` |
| 사후검토 | 1초 프레임 기록, 먼저 본 쪽·노출 시간·주요 사건, "실제 vs 내가 본 것" | `aar.ts` |

검증 수치 (headless, mg-nest 30판): 지원 위치 제압 → 15m 에서 사격 전환 → 돌입 16승 / 제압 없이 9승 / 전원 정면 돌격 0~1승.
사격 전환을 35m 에서 하면 제압 효과가 사라진다 (적 회복 ~10초).

## 실 개발에서 바꾸는 것
- **명령을 데이터로** (`Command`, 틱 경계 적용). POC 는 함수가 상태를 바로 바꿔 리플레이가 불가능했고, 사후검토는 프레임 녹화에 의존했다.
- **정수 틱** 시간 (POC 는 부동소수 `t` 를 반올림).
- **패키지 분리**로 시뮬에 DOM·Node 가 섞이지 않게 강제.

## 열린 질문 (플레이하면서 정할 것)
- 경유점 지정 (POC 에서 경로 탐색이 적 시야를 모르고 노출된 길로 가는 문제).
- 지점 제압의 전용 취소·전환 조작 (POC 는 사격 통제 순환으로만 해제).
- 렌더링: Canvas 2D 로 시작. 인원·효과가 늘어 느려지면 WebGL(PixiJS 등) 검토.
- 시나리오 형식, 적 AI 구조, 저장/불러오기.
- 여단 확장 대비: 임무 부여 구조(POC `squadtask`)를 제대 공통으로, 먼 부대는 사람 단위 대신 부대 단위로 묶어 계산할지.
- 과정(캠페인) 구조: 과정별 지휘 제대, 수료·승급 조건, 한글 제목/부제.
