# 설계 메모 — 정한 것과 열린 질문

실 개발은 이 문서를 기준으로 한다. 현재 코드 구조는 [`ARCHITECTURE.md`](ARCHITECTURE.md).

## 방향
- 제목 **TCTP — Tactical Command Training Program** (2026-10-15). MCTP·BCTP 식 전투지휘훈련 게임.
  가상의 훈련 과정이며 실제 프로그램(MCTP·BCTP, 전투지휘훈련단) 이름·휘장은 쓰지 않는다.
- 과정 사다리: 분대·소대(직접 지휘) → 중대·대대(임무 부여, 하급 제대 AI 수행) → 여단(지휘소에서 보고·명령, 명령 지연·보고 모델).
  훈련 요소 = 실제 지도 훈련장, 같은 규칙의 대항군, 사후검토.
- 첫 제품은 **분대장 지휘**. 소대장 지휘(분대에 임무를 주고 분대장 AI 가 수행)는 이후 단계.
- 핵심 재미: 분대장이 **지점 제압 → 기동 → 사격 전환 타이밍 → 돌입**을 직접 판단하는 것.

## 캠페인 구조 (2026-10-15)
- 분대에서 시작해 제대가 점점 커지는 캠페인. WARNO 의 Army General(캠페인 고르기 → 진영 → 전략 지도 → 전투 계획 → 배치 → 전투 시작) 흐름과 어두운 지도판·호박색 강조 화면을 참고한다.
- 첫 화면 = 과정 고르기. 이름 TCTP 에 맞춰 **TACTICAL** (분대·소대 직접 지휘), **COMMAND** (중대·대대 임무형 지휘), **STAFF** (여단 지휘소). 지금은 TACTICAL 만 열려 있다.
- TACTICAL → 제대 과정 사다리(분대 → 소대, 위로 갈수록 잠김) → 과정의 훈련 목록 → 브리핑 패널(브리핑 · 편제 · 장비 탭) → 훈련 시작.
- 편제 탭은 시나리오 부대를 편제대로 세운 결과(조·직책·이름·화기)를, 장비 탭은 화기 성능표를 보여 준다.
- 분대 과정의 첫 훈련 = 미 육군 **배틀 드릴 1 접적 시 행동** (ATP 3-21.8). 이후 후보: 배틀 드릴 2 접촉 단절, 2A 분대 공격, 3 매복 대응.
- 데이터: [`content/campaign.json`](../content/campaign.json) (과정·훈련 목록), [`content/scenarios/*.json`](../content/scenarios) (지도·시드·브리핑·부대), [`content/orgs/*.json`](../content/orgs) (편제), [`content/equipment.json`](../content/equipment.json) (화기·탄약), [`content/names.json`](../content/names.json) (이름 생성).

## 객체 (최소 정의, 2026-10-15)
| 객체 | 가진 것 |
|---|---|
| 병사 | 이름, 직책, 소속(분대·조), 몸 크기 가로·세로·높이 (기본 0.5 × 0.3 × 1.75m, 피탄 판정용), 휴대 장비 (장비 id + 수량) |
| 화기 | 직사/곡사, 탄약, 유효사거리, 장전 수, 무게 |
| 탄약 | 구경, 한 발 무게, 관통력 (mm 강판 상당), 폭발 여부, 폭발 반경, 제압 반경 |
| 편제 | 조 → 직책 → 휴대 장비, 근거 자료와 추정한 부분(note). 시나리오는 편제 id 로 부대를 세운다 |

- 국군 소총분대 **8명**: 2020년부터 평·전시 8명 (기존 전시 10명 = 분대장·부분대장·소총수 4·유탄수 2·기관총 사수·부사수에서 소총수 2명 감소로 추정. 직책별 인원은 2차·추정, [조사 노트](research/67-org-bd1.md)). 화기 K2·K201·K15.
- 북한군 보병분대 **12명** (ATP 7-100.2 North Korean Tactics 3-73): 분대장 AK, 부분대장 AK+G-25, 기관총수 3 RPD, 부기관총수 3 AK, 대전차수 2 RPG-7+AK, 유탄수 AK+G-25, 저격수 SVD.
- 두 편제 모두 조 나누기와 휴대 수량은 추정. 장비 수치는 공개 자료 기준 대략값.
- 사격·제압 판정은 [`combat/fire.ts`](../packages/sim/src/combat/fire.ts) ([calc/fire.md](calc/fire.md)). 수치는 대략값, 플레이하며 맞춘다.

## 명령 구조 (2026-10-15)
`Command`(입력, 기록) → `Order`(분대·조 임무) → `Action`(병사 개인 행동) → 장비 트리거. 자세한 것은 [objects/action.md](objects/action.md).
- 사건마다 작은 흔들림(`VARY`: 반응·걸음·서는 자리·조준·점사·재장전·스트레스)을 준다. 병사가 획일적으로 움직이지 않게 하되 능력치는 아니다 (2026-10-15).
- 소총탄 제압 반경 2m (사용자 결정) → #17 에서 구경별 3·4·5m 로 바꿈 ([calc/rates.md](calc/rates.md) "제압 수치 근거"). 지점 제압사격은 둘레 4m 를 쓸어 쏜다.
- 행동은 무엇을 할지만 정하고, 결과(명중·속도)는 장비와 몸 상태가 정한다. 조준사격·제압사격은 같은 화기 트리거를 조준점·조준 시간·발 수만 다르게 당긴다.
- 플레이어는 리더(분대·조)에 임무를 주고, 리더 로직이 조원 행동을 고른다 (최소 명령 단위 = 분대). 교전규칙도 리더가 행동을 고르는 방침.
- 구현 순서: ① 행동 틀 + 이동 (**구현됨**) ② 화기 트리거·`Shot`·조준사격·제압사격·재장전 (**구현됨**. 클라이언트: 아는 적 우클릭 = 조준사격, Shift+우클릭 = 지점 제압·전환, X = 사격 그침, 스냅샷의 탄 자취·탄착·폭발 표시) ③ 리더 로직·임무·교전규칙(hold/return/free, 리더가 행동을 고르는 방침 — 채택), 수류탄·개인호.

## 시뮬 모델 (옮겨 올 목록)
| 영역 | 정한 것 |
|---|---|
| 지형 | OSM 벡터 → 1m 격자 (밀도·은폐·엄폐·통행), 고도 4m 격자 쌍선형, 고도 시선·능선 엄폐 — **구현됨** (지물 높이·시야 감쇠·은폐·엄폐·이동 배율 표 `TERRAIN`) |
| 이동 | 사람 간 최소 1m — **구현됨** (겹치면 떼어 놓고, 걷는 병사가 선 병사를 비켜 감, 여럿을 한 점으로 보내면 둘레에 나눠 섬), 낮은 자세 걷기 ×0.8 · 포복 ×0.6. 지금은 목표점까지 직선 이동 — 2m A* + 경사 비용·경로 선택은 계획 ([#24](https://github.com/DeveloperRyou/tctp/issues/24)) |
| 시야 | 양안 120° 온전, 주변 200° 까지 감소, 그 밖은 총성만 — **구현됨** (발견 조건 x: 거리·크기·시선 투과·은폐·움직임·사격 → 임계 아래면 영영 못 찾고 위면 탐색 시간 안에 찾음, 진영 공유, 놓친 적은 30초 기억). 총성은 사격과 함께 |
| 사격 | 부위별 부상·방호구 내구도·폭발, 사격 품질(걷기·제압 시 저하) |
| 제압 | 받는 제압 ×= 기본 + 엄폐 계수 × (발밑·사격 방향 시선 엄폐 중 작은 값). 이동 중 ×1.15 |
| 지점 제압 | 지점 주변 반경 4m 를 쓸어 쏨 (`FIRE_ORDER.suppress.sweep` 고정 — 사격 단위가 폭을 정하게 바꾸는 건 [#28](https://github.com/DeveloperRyou/tctp/issues/28)), 진지 안 적 전원 제압, 직격 드묾 |
| 상태 | 제압·사기·출혈·수분·응급처치(구급품 소모) |
| 장비·자원 | 탄약, 수류탄·유탄, 붕대·지혈대, 수통, 방탄모·방탄복 내구도, 쌍안경·무전기, 하중 |
| 사후검토 | 먼저 본 쪽·노출 시간·주요 사건, "실제 vs 내가 본 것". 명령 기록 리플레이로 재구성 |

밸런스 기준: 지원 위치에서 제압하고 가까이서 사격을 전환해 돌입하는 쪽이, 제압 없이 또는 정면 돌격보다 확실히 이겨야 한다.

## 열린 질문 (플레이하면서 정할 것)
- 경유점 지정 (경로 탐색이 적 시야를 모르면 노출된 길로 간다). → **구현됨** (#64): 이동 명령의 `via`, 클라이언트 Ctrl+우클릭으로 경로 끝에 이어 붙임. 경유점 사이는 아직 직선 (#24 경로 방식).
- 렌더링: Canvas 2D 로 시작. 인원·효과가 늘어 느려지면 WebGL(PixiJS 등) 검토.
- 적 AI 구조.
- 경로 탐색이 없어 통행 불가 칸(건물·물) 앞에서 멈춘다.
- 자세(낮은 자세·포복)가 생기면 눈높이·표적 높이·은폐에 반영.
- 근거 확인: 국군 8명 분대의 직책 구성은 공식 1차 출처 없음(총원 8명만 2차 일치, 직책별 인원 추정) — [조사 노트](research/67-org-bd1.md). 배틀 드릴 1 은 ATP 3-21.8 2016판 부록 J 단계 확인, 2024판 BD 1A 단계만 미열람.
- 여단 확장 대비: 임무 부여 구조를 제대 공통으로, 먼 부대는 사람 단위 대신 부대 단위로 묶어 계산할지.
- 과정(캠페인) 구조: 과정별 지휘 제대, 수료·승급 조건, 한글 제목/부제.
