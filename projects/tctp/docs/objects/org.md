# 편제 `OrgTemplate`

제대의 조 구성과 직책별 휴대 장비. 코드: `packages/sim/src/org.ts`. 데이터: `content/orgs/<id>.json`.
시나리오는 편제 id 로 부대를 세우므로, 편제를 고치면 그 편제를 쓰는 모든 시나리오에 반영된다.

## 형식

`OrgTemplate`
| 필드 | 뜻 |
|---|---|
| `id`, `name` | 식별자, 표시 이름 |
| `nation` | 소속 군 (대한민국 육군, 조선인민군 …) |
| `echelon` | 제대 `"squad" \| "platoon" \| "company" \| "battalion" \| "brigade"` |
| `kit` | `LoadoutItem[]` (선택) — 모든 구성원 공통 장구. 각 구성원 `loadout` 앞에 붙는다 |
| `teams` | `OrgTeam[]` — 순서대로 병사 id 가 매겨진다 |
| `source` | 근거 자료 |
| `note` | 근거에 없어 추정한 부분 (선택) |

`OrgTeam`: `name` (조 이름, 부대명 뒤에 붙음), `members: OrgMember[]`.
`OrgMember`: `role` (직책), `leader` (조장, 선택), `loadout: LoadoutItem[]` ([soldier.md](soldier.md)).

함수: `strengthOf(org)` = 인원 수, `checkOrg(org, catalog)` = 구성원마다 공통 장구 + 직책 장비를 합쳐 없는 장비·탄약, 화기 칸(주 1·보조 1), 무게 한도(몸무게 × 0.7) 오류 목록.

근거: 2020년부터 평·전시 8명 (기존 전시 10명 = 분대장·부분대장·소총수 4·유탄수 2·기관총 사수·부사수). 8명 직책 구성은 소총수 2명 감소로 추정, 조 나누기·수량은 추정.

확인 (#7, 2026-10-15): 나무위키 [분대](https://namu.wiki/w/%EB%B6%84%EB%8C%80)·[소총수](https://namu.wiki/w/%EC%86%8C%EC%B4%9D%EC%88%98) — 전방 사단 완편 8명 (분대장·소총수·유탄수 2·기관총 사수·부사수), 2020년부터 평·전시 구분 없이 8명. 인원·직책·화기(K2·K201·K15)가 당시 편제와 맞았다. 다른 점: 부분대장은 공식 직책이 아니다 (선임 분대원이 2조를 맡는 운용으로 보고 그대로 둠). 후방 사단은 기관총 사수·부사수 대신 자동소총수 2명 + 소대 화기분대 — 이 편제는 전방 사단 기준. 나무위키는 판본마다 내용이 달라 공식 교범으로 재확인 필요.
