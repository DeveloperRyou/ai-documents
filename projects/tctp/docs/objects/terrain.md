# 지형 격자 `Terrain` · 칸 성질 `TerrainProps`

코드: `packages/sim/src/terrain.ts`. 데이터는 따로 없고 지도(`MapData`)에서 굽는다.
`terrainOf(map)` 가 지도 객체마다 한 번 만들어 캐시한다 (라스도르프 1199 × 1001 칸에 약 60ms). 판 중에 바뀌지 않는다.

## `Terrain`
| 필드 | 뜻 |
|---|---|
| `w`, `h` | 칸 수 (칸 = `TERRAIN_CELL` = 1m) |
| `kind` | 칸마다 지물 종류 번호 (`Uint8Array`) |
| `elev` | 고도 격자 `ElevationGrid { cell, w, h, z: Float32Array(m) } \| null` |

읽기: `kindAt(t, x, y)` 종류, `propsAt(t, x, y)` 성질, `elevAt(t, x, y)` 고도(쌍선형, 격자 없으면 0), `floorAt(t, x, y)` 발 딛는 높이 = 고도 − `depth`.

## 굽는 규칙
- 칸마다 종류 하나. 겹치면 나중에 굽는 것이 이긴다.
- 면: 칸 중심이 다각형 안이면 칠함. 순서 residential → farmland → grass → orchard → scrub → wood → water → building.
- 선: 칸 중심이 선분에서 반폭 이내면 칠함 (최소 폭 1m). 순서 stream → river → ditch → trench → path → track → road → fence → hedge → wall.
- 고도: 지도의 base64 Int16LE(0.1m)를 직접 디코드 (`decodeBase64`, `decodeElevation`).

| 성질 | 쓰는 곳 |
|---|---|
| `height`, `density` | 시선: 시선이 지면+`height` 아래를 지나면 1m 마다 `density` 누적, 투과율 = exp(−합) |
| `concealment` | 탐지: 표적이 선 칸의 은폐만큼 발견 확률 감소 (움직이면 절반) |
| `cover` | 제압: 근탄 스트레스 × (1 − 0.6 × 엄폐), 스트레스 회복도 빨라진다 |
| `move` | 이동: 걷기 속도 × 선 칸의 배율. 다음 칸이 0 이면 그 자리에 선다 (경로 탐색 없음) |
| `depth` | 파인 깊이 (m). `DEPTH` = ditch 0.8, trench 1.2, 나머지 0. 아래 "파인 땅" |

## 파인 땅 (`depth`: 도랑·참호)
고도 격자(5m 안팎)로는 도랑을 팔 수 없어 칸 성질로 둔다.
- 그 칸에 선 사람의 발은 `floorAt` (지면 − 깊이). 몸 높이·조준점·눈높이가 모두 여기서 잰다.
- 둔덕: 표적에서 상대 쪽으로 `RIM.reach`(3m) 안에서 처음 나오는 안 파인 칸 끝 (`rimDist`). 그 안에 없으면 (참호를 따라 보면) 가리지 않는다.
- 시야: 둔덕 끝을 스치는 선보다 위의 몸 비율(`rimExposure`)만큼 투과율이 준다. 평지에서 보면 참호 속 선 사람 ≈ 머리·어깨만, 앉거나 엎드리면 0. 높은 데서 내려다보면 더 보이고, 낮은 데서 올려다보면 스치는 선이 위로 기울어 덜 보인다 (벼랑 아래에서는 머리까지 가린다). 관측자가 파인 칸에 있으면 눈이 둔덕 너머로 나와야 본다.
- 사격: 탄도선이 둔덕 끝에서 지면보다 낮으면 흙에 막힌다 (평지 사격에 배·다리는 안 맞는다). 조준점은 둔덕 위로 드러난 몸 가운데보다 낮지 않다 (`aimZ`). 둔덕 안 바닥은 비어 있어 탄도선 검사는 바닥 높이로 한다. 폭발 파편도 같은 비율로 막힌다.
- 서서 쏘는 총구 높이 ≈ 1.5m 라 참호(1.2m) 속에서는 서야 밖으로 쏜다. 앉으면 몸도 총도 둔덕 아래.
