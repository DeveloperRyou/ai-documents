# #39 응급처치 행동: 처치 시간·효과·보급

조사일 2026-10-16. 앞선 조사 [39-61-aid.md](39-61-aid.md) (TCCC 지혈대·지혈 거즈 3분)를 이어, 이슈 수락 기준에 필요한 **시간·효과 수치**를 찾았다. 초록은 Europe PMC 에서 받았다. 본문(PDF)은 NATO STO 403, PMC reCAPTCHA, PubMed 쿠키 벽으로 못 열었다. 그래서 표의 숫자는 초록에 적힌 것까지만 `확인`(초록)으로 두고, 본문 표가 필요한 것은 `2차`로 둔다.

## 지금 코드

- 출혈은 멈출 수단이 없다 (`docs/calc/rates.md` "지금은 출혈을 멈출 방법이 없다"). 부상마다 `RATES.blood.bleed[부위][정도]` mL/초 (±40%), 혈액 `WOUND.blood` 5000 mL, 약해짐 30%·실신 40%·사망 50%.
- 부위 표: 사지 중상 3, 치명 12 / 몸통 중상 6, 치명 15 / 배 중상 5, 치명 12 mL/초.
- `armUse` 가 `none` 이면 두 팔 다 못 씀 → 수락 기준의 "두 팔 다 못 쓰면 자기 처치 불가"는 이미 있는 판정으로 쓸 수 있다.
- 구급 물자(지혈대 개수)는 장비에 없다. `rok-kit` 에 "구급낭"이라는 글만 있고 수량 필드가 없다.

## 제안 (코드는 건드리지 않음)

1. **처치 시간**: 기준 시간(`baseTreatTime`, 초) × 처치 종류 계수. 지혈대 30초(2차 29초), 자기 처치는 전우 처치보다 5초 길게(`selfCoef` 대신 차이로 두면 Wang 과 맞음. 곱 계수로 쓰면 30 대 25 = 1.2). 압박 붕대(지혈 거즈)는 TCCC 3분 = 180초 확인값 쓰기. 스트레스 계수는 크기 근거가 없으니 추정으로 표시하고 사용자 승인을 받기.
2. **효과**: 사지 부상에 지혈대 → 그 부상 `bleed` 를 0 으로. 성공률은 두 갈래 근거(Kragh CAT 79%, Wang 맥박 소실 자기 처치가 전우보다 11~13%p 낮음)로 `성공 확률` 필요. 승인할 값: 79%(현장 효과)를 전우 처치 기준으로, 자기 처치는 -11~13%p. 실패하면 물자는 쓰이고 출혈은 그대로이며 재시도 가능.
3. **몸통·배**: 지혈대 불가. 압박 붕대로 `bleed` 를 줄이는 비율은 근거가 없다. Eastridge 67.3% 가 몸통 출혈이라는 사실은 "압박 붕대로도 못 막는 큰 몫이 있다"는 서술적 근거. 선택지: 줄임 계수를 추정으로 두고 명시하거나, 이슈 수락 기준대로 "느려지되 멈추지 않음"만 구현하고 수치는 사용자가 정함.
4. **수락 기준 대조**: 사지 지혈대 정지, 두 팔 불가 시 자기 처치 거부(`armUse==="none"` 재사용), 몸통은 느려질 뿐, 물자 없으면 거부는 구현 가능. 둘 다 바쁨·중단·상호 처치는 시뮬 규칙이라 근거 불필요. 단 **수량(지혈대 몇 개)** 과 **몸통 감소율** 은 근거 부족.
5. **필요한 결정**: (a) 지혈대·붕대 기본 수량, (b) 몸통 감소율, (c) 스트레스 시간 계수, (d) 성공률 79% 대 Mulet 37% 중 선택. 이 넷은 `needs-decision` 에 해당한다.
6. **반영 시**: `docs/calc/rates.md` 에 응급처치 절, `calc-charts.ts`·`npm run charts`, `docs/objects/action.md`, 드릴(자기·전우·상호·중단·물자 없음). 이 파일의 "반영" 칸에 커밋을 적는다.
