## TCTP 에 옮기면 (제안, 미반영)

- 1차 근거(Friedman 2019 식 2)와 맞는 구조: P∞ 를 "임계": 조건(거리·자세·은폐 투과·움직임)으로 P∞ 를 계산하고, P∞ 가 아주 작으면 0 으로 둔다 → 오래 봐도 못 찾는다.
- 원문대로 조건(거리·배경)이 바뀌면 P∞·τ 를 다시 계산한다. 지금의 매 초 굴림 대신, 조건이 바뀔 때 P∞ 로 "결국 찾을지"를 한 번 굴리고, 찾는다면 τ 를 평균으로 하는 지수 분포에서 발견 시각을 뽑는다. 조건이 바뀌면 다시 굴린다.
- 이슈 본문의 사용자 기준(개활지 400m 움직이는 표적 1~3초, 은폐된 표적 5초~수십 초 또는 영영)은 τ·P∞ 목표값으로 쓸 수 있다. 이 값들은 출처가 사용자 메모라 `추정`.

## 현재 코드 수치와 차이 (docs/calc/vision.md 3절, `VISION`)

현재: p = min(0.95, 0.36 × min(1,(60/d)²) × 시야각 × shown × 움직임 2 × …), 한 틱 확률 = 1 − (1−p)^0.25, 매 틱 굴림. 임계 없음: shown > 0 이면 언제든 p > 0.

| 경우 | 현재 값 (식으로 계산) | 이슈 기대 | 차이 |
|---|---|---|---|
| 개활지 400m 걷는 표적, 관측자 1명 정지 | 0.36 × 0.0225 × 2 = 0.0162/초 → 평균 약 62초 | 중앙값 1~3초 | 20~60배 느림. 분대 8명이 함께 봐도 약 8초 |
| 같음 300m (calc 표) | 서 있음 0.014 (71초), 걷기 0.029 (34초) | — | 400m 는 거리² 감쇠로 급락 |
| 숲 가장자리 은폐 0.6 가만히 엎드림 50m (calc 표) | 0.012/초 → 평균 약 83초 | 임계 아래면 영영 | 지수 분포라 10분(600초) 안에 거의 확실히(1−e^(−7.2)≈99.9%) 발견됨 → 수락 기준 "0%" 위반 |
| 은폐 1.0 | shown = 0 이면 p = 0 | — | 완전 은폐만 임계처럼 동작 |

해석: 현재 모델은 이슈가 지적한 대로 p > 0 이면 시간이 모든 것을 드러낸다. 그리고 먼 거리의 움직이는 개활지 표적은 이슈 기대보다 한참 느리다. 거리 감쇠가 (60/d)² 로 너무 가파르다.

## 제안 (미반영, 코드·상수·docs/calc 수정 없음)

1. 임계(P∞): 조건 조합으로 "분해 가능한 주기 수 N = 표적 크기 × shown × 대비 계수 ÷ 거리" 를 만든다. N ÷ N50 이 임계 아래이면 P∞ = 0 (영영 못 봄). N50 기준 `baseN50` 은 Johnson 탐지 1.0 주기(2차)를 출발값, 잡음(은폐) 쪽은 TTP 표 6.2 의 0.75~1.7 범위(확인)를 은폐 계수 범위로 쓴다. 사람 표적의 실제 N50 은 `추정`.
2. 확률 꼴: P∞ = (N/N50)^E / (1 + (N/N50)^E) 꼴(TTPF, 확인 필요)로 두고, P∞ < `minDetect`(추정) 이면 0.
3. 탐색 시간: 조건이 바뀔 때만 "결국 찾는가" 를 P∞ 로 한 번 굴리고, 찾으면 발견 시각 = 지수 분포 (평균 τ). τ = `baseSearchTime` × (거리, 은폐, 움직임 계수), Friedman 2019 식 2 의 방향(잡음·거리 ↑ → τ ↑, P∞ ↓) 확인. τ 값은 이슈 사용자 메모(개활지 400m 이동 1~3초, 은폐 5초~수십 초)에 맞추는 `추정`.
4. 일시 단서(사격·급한 움직임): 짧은 창 동안 N 에 가산하고 창이 끝나면 되돌린다. 지속 가산 금지.
5. 새 난수 굴림이 생기므로 `docs/calc/random/rolls.md` 갱신 필요. 결정성은 시드 RNG + 조건 변화 시점 굴림이면 유지.
6. 수락 기준 대응: 10분·200시드 0% 는 P∞ = 0 이어야 성립. 조건 변화(움직임·사격·일어섬)가 오면 다시 굴린다.
7. 관측자 여럿: 각자 독립 P∞·τ 로 굴리고 가장 빠른 발견 시각을 쓴다(Friedman 의 하이퍼지수는 정지 관측자 여럿 때 더 맞다는 초록, `2차`).

사용자 결정 필요: 사람 표적의 N50 과 τ 목표를 추정으로 두고 가도 되는지, 아니면 사람 표적 N50 원문(NVESD 사람 탐지 연구)을 더 찾을지.
