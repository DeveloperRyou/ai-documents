# #66 BD3 매복 대응 절차

조사일 2026-10-16.

## 확인

출처: FM 3-21.8 (2007) 그림 6-3 "Battle Drill 3 — React to Ambush" 사본 ([Boise State 사본](https://boisestate.edu/sps-militaryscience/wp-content/uploads/sites/123/2014/04/reactotambush.pdf), 쪽 6-7). 사본은 교범 한 쪽 발췌라 판·쪽 표기만 그림 아래에 있음.

| 단계 | 내용 |
|---|---|
| 상황 | 분대·소대가 살상지대에 들어서고, 적이 살상 장치와 다량 사격으로 매복을 개시 |
| 근접 매복 (수류탄 거리 안) | 살상지대 안 병사는 즉시 응사. 엄폐 없으면 명령·신호 없이 엎드려 충격·파편·연막 수류탄 투척. 엄폐 있으면 가까운 엄폐로 가서 엎드려 투척. 폭발 직후 응사하며 사격과 기동으로 매복 진지를 돌파 |
| 살상지대 밖 | 적 위치를 식별하고, 돌파가 시작되면 사격을 전이 |
| 원거리 매복 | 사격 받는 병사는 즉시 응사하고 엄폐해서 적 승무원 화기를 파괴·제압하고 제압 사격을 유지. 사격 받지 않는 조는 은폐된 경로로 적 취약 측방에 가서 사격과 기동으로 돌격. 소대 FO 가 간접사격 |
| 마무리 | 보고, 재편성, 임무 계속 |

## 번호 충돌

- 이 판(2007)은 BD3 = 매복 대응. 2016/2024 ATP 3-21.8 은 번호를 다시 매겨 매복 대응이 BD4 라는 설이 있다(Task & Purpose, 팟캐스트 — `2차`). `docs/research/67-org-bd1.md` 는 2024판에서 BD 4/4A 가 매복 대응이라고 적어 둔다 → 이슈 제목의 "BD3"는 구판 번호.

- 성공 조건(수치): 교범에 없음. 시나리오 설계자가 정해야 한다.
