# #39·#61 응급처치·후송

조사일 2026-10-16.

## 확인

출처: TCCC 지침 ([해병 사본](https://www.tecom.marines.mil/Portals/120/Docs/Student%20Materials/TCCC%20Guidelines.pdf), 판 연도는 문서에 없음, 2021 이전 판으로 보임).

| 항목 | 값 |
|---|---|
| 지혈대 | 사지 출혈은 지혈대를 옷 위에서 출혈 부위보다 몸쪽에 바로 맨다. 위치 불명이면 "높고 단단히". 맨 시각을 지혈대에 적는다 |
| 지혈 거즈 | 압박 가능한 출혈(지혈대 부적합)은 지혈 거즈를 대고 **최소 3분** 직접 압박 |
| 접합부 출혈 | 접합부용 지혈대를 바로 적용 |
| 재평가 | 급할 때 맨 지혈대는 옷 위→피부 2~3인치 위로 바꿔 매고, 새면 조이거나 두 번째를 옆에 맨다 |
| 지혈 소요시간(초) | 이 사본에는 없음 |

(1) 2차: [JSOM 2016 p.66](https://www.jsomonline.com/Flipbook/Journals/1601-Spring/files/basic-html/page66.html) 접합부 장비 적용 29~37초, "54초 넘으면 너무 느림" — 장비 시험 보고.

## 못 찾음

- 끌기·업기 속도(m/s)와 체력 소모: FM 4-25.11·TC 4-02.1 본문을 못 받음. 검색에서는 끌기·업기 종류만 나옴(목끌기, 소방관식, 팩 끈).
- 자기 처치 소요시간, 가슴·배 출혈에 지혈대가 효과 없다는 서술은 TCCC 일반 서술 수준.
