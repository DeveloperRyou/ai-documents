# #49 경사: 이동 속도와 체력

조사 2026-10-16 (2차 갱신). 지금 코드: 이동은 경사를 보지 않는다. 속도 = `BASE_SPEED` × 하중 × 지구력 × 다리 × 실혈 계수 × 선 칸 `move` 계수 ([calc/movement.md](../calc/movement.md)), 지구력 소모 = `RATES.stamina.drain[자세]` × (1 + 하중 비율 × 2) ([calc/rates.md](../calc/rates.md)). 고도 격자 `elevAt(t,x,y)`(`terrain/terrain.ts`)는 이미 있다 (시야·사격용).

## 1차: Santee 외 2003 (USARIEM) — 경사별 에너지 소모

Santee, W. R., Small, M. G., Blanchard, L. A. (2003) *Journal of the Human-Environment System* 6(2): 69–76. [J-STAGE](https://www.jstage.jst.go.jp/article/jhes/6/2/6_2_69/_article). PDF 본문을 받아 읽었다 (8쪽, 1~2쪽). 이 논문이 Santee 외 2001 실험실 모형의 식을 옮겨 적었다.

| 항목 | 식·값 | 등급 | 조건 |
|---|---|---|---|
| 평지 소모 | W_L = 3.28·m_t + 71.1 [W] (Passmore & Durnin 1955 에서) | 확인 | m_t = 몸 + 옷 + 짐 + 장비 총질량 kg |
| 오르막 | W_UP = W_L + 3.5·(m_t·g·h/s) [W] | 확인 | g = 9.8, h = 1.34 m/s 로 걸을 때 초당 수직 이동 m. 트레드밀 |
| 내리막 | W_DOWN = W_L + 2.4·(m_t·g·h/s)·0.3^(α/7.65) [W] (h 가 음수라 소모가 준다) | 확인(식 모양), 글자 깨짐 | α = 경사각(°). PDF 글리프가 깨져 `0.3^(α/7.65)` 의 지수 위치는 문맥으로 읽음 — 원 논문(2001)으로 재확인 필요 |
| 시험 조건 | 걷기 1.34 m/s, 짐 0·13.6·27.2 kg, 내리막 0·4·8.6·12 %, 현장 시험은 Yakima 훈련장 자갈길 | 확인 | |
| 흙길 지형 계수 | 1.1 (Soule & Goldman 1972) | 확인(재인용) | 같은 논문 2쪽 |
| 검증 | 내리막 식은 현장 자료와 맞음, 오르막 8.6% 는 안 맞음(p<0.001), 현장 변동이 큼 | 확인 | 논문 Discussion |

계산 예 (m_t = 100 kg, 1.34 m/s, 내가 식에 넣어 계산 — 식의 응용이라 추정 아님):
- 평지 W_L = 399 W. 오르막 +10%: h = 0.134 m/s → 399 + 3.5·100·9.8·0.134 = 859 W (평지의 **2.15배**). +20% → 1318 W (**3.3배**).
- 내리막 −10%: α = 5.7°, 0.3^(0.746) = 0.41 → 399 − 128 = 271 W (**0.68배**). −20%: α = 11.3° → 292 W (**0.73배**). 내리막이 가장 싼 경사는 약 −8~−10% 근처, 더 가팔라지면 다시 오른다 (Margaria·Santee 보고와 같은 모양).

## 반영안 (제안 — 코드·docs/calc 는 아직 안 고침)

수락 기준: (1) 가파른 오르막이 평지보다 느리고 더 지침, (2) 아주 가파르면 훨씬 느리거나 통행 불가, (3) 드릴 + 같은 시드 → 같은 stateHash.

1. **속도: 경사 계수 `slopeCoef(S)`** (신규, `speedOf` 에 곱하는 계수 한 항, S = 한 걸음의 `(elevAt(다음) − elevAt(현재)) / 걸음 수평거리`, 오르막 +):
   - 꼴: `slopeCoef = exp(−3.5·|S + 0.05|) / exp(−3.5·0.05)`, 즉 Tobler 를 평지 1 로 정규화 (`slopeSteep` 3.5, `slopeOffset` 0.05 두 상수). 등급: 식은 확인(논문이 옮긴 것), 원문은 2차.
   - 내리막 과대 지적 때문에 **상한 1.0 으로 자르는 안**을 권장 (`min(1, …)`). 이 결정은 사용자 승인이 필요 — 교범(1차)은 "내리막도 느려진다"만 말하고 Tobler 는 −5% 부근에서 빨라진다. 자르면 교범과 논문 비판 둘 다와 맞는다.
   - 문턱: ATP 3-21.18 의 7% 미만은 영향 없다고 볼 수 있으나 Tobler 곡선은 연속이라 따로 문턱을 두면 곡선이 끊긴다. 곡선만 쓰고 7% 는 확인장 설명에 인용하는 안이 단순.
2. **지구력: 경사 소모 계수 `slopeDrainCoef(G)`** (`RATES.stamina.drain` 에 곱함, 하중 항 `(1 + r×2)` 과 곱):
   - 오르막: `1 + slopeUpCoef × G` 꼴. Santee 가 100 kg 에서 평지 대비 +10% → 2.15, +20% → 3.3 이므로 `slopeUpCoef ≈ 11.5 per 1.0 grade` (기울기 10% 당 +1.15). 단 이 값은 m_t = 100 kg 가정이고 질량이 크면 평지 항 대비 비율이 달라진다 — 병사별 m_t 로 계산하는 안도 있으나 `STAMINA` 은 지금 무차원 비율이라 `slopeUpCoef` 한 값(추정으로 표시)이 단순.
   - 내리막: Santee 식은 −8~−10% 에서 약 0.7배로 최저, 더 가팔라지면 오른다. 단순화: 내리막 −10% 이하는 0.7 로 평탄 처리하거나 위 식(0.3^(α/7.65))을 쓴다. 지수 위치 확인 전이라 **내리막은 보류하고 오르막만 먼저** 넣는 안을 권장.
3. **통행 한계**: 출처가 없다. 선택지: (a) 속도 계수가 0.1 아래로 못 내려가게 하한(`slopeMinCoef` 0.1, 추정)을 두고 Tobler 가 이미 +50% 에서 0.17배인 점을 근거로 삼는다. (b) 사용자가 정한 임의 한계(예: 60%)를 `추정`으로 넣는다. 사용자 결정 필요.
4. **#24 경로 비용**: 같은 `slopeCoef` 의 역수(= 시간 비용)를 간선 비용에 곱한다. 시간 = 거리 / (속도 × slopeCoef).
5. **고정할 지점**: 걸음 단위 기울기는 격자 해상도(고도 격자 간격)에 따라 거칠다. 고도 격자 보간이 쌍선형이면 한 틱 걸음(≈0.35 m)으로 S 를 재면 잡음이 크다 → 몇 m 앞(`SLOPE.lookahead`, 추정)을 보고 재거나 격자 변 단위로 잰다. 결정성: 격자 읽기는 결정적이라 `stateHash` 영향은 새 계수가 곱해진 값뿐이다.
6. **드릴(e2e)**: 평지 / 오르막 +10% / +30% / 내리막 −10% 에서 같은 거리를 걷는 시간과 지구력 소모 비교, 한계 드릴. 새 상수는 `docs/calc/movement.md`, `rates.md`, `calc-charts.ts` 에 곡선 추가 후 `npm run charts`.
