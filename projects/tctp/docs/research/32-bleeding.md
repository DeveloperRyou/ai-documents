조사일 2026-10-16 (2차 조사: 첫 조사의 2차 표를 그대로 두고, 본문을 연 항목을 더함). 이슈 #32: 부위×정도 출혈 mL/초 ±40%, 약해짐 30%·실신 40%·사망 50% (혈액 5 L)가 현실과 맞는지, 근거를 달아 확률 기반으로 정리.

## 추정

- 목표 시간 방식: 절대 속도 대신 "사망까지 몇 분" 을 목표로 두고 거꾸로 맞춘다. 사지 동맥·치명 수 분(1~5분), 몸통 치명 2~5분, 몸통·복부 중상 수 분~십수 분, 사지 정맥·중상 십수 분 이상, 경상·찰과는 시나리오 길이(수 시간) 안에 사망하지 않음. 이 구간은 위 2차(동맥 수십 초~수 분, 대량출혈 1~2분, 지혈대 3분 안에 필요)와 방향이 맞는 판단이지 숫자 출처가 아니다.
- 팔다리 치명 12 mL/s(=720 mL/분), 몸통 치명 15 mL/s 는 수 분 사망이 되도록 고른 값이라는 점에서 코드 주석("6 mL/s ≈ 7분")과 같은 논리다. 생리학적 혈관 유량으로 검증하지 않았다.

## 판단

- 문턱(30·40·50%)은 ATLS 분류와 방향이 맞다 (확인한 Table 1: 30~40% 가 III, >40% 가 IV 전쇼크). 사망 50% 는 class IV 위쪽 문턱을 넘긴 값으로 타당하나, 40% 에서 실신(무력화)으로 두는 것은 class IV 가 시작되는 지점이라 합리적이다. 약해짐 30% 는 class III 시작과 일치.
- 사지 중상 3 mL/s 로 14분: 지혈대가 쓰이는 사지 출혈이 "살릴 수 있는 사망" 의 주역이라는 Kragh·Eastridge 서술과 어긋나지는 않으나, 숫자 근거는 없다. 몸통이 전장 치명 출혈의 67% 라는 2차 숫자는 몸통 치명·중상이 가장 빨리 죽는 현재 표(가슴 6~15)와 방향이 같다.
- 근거가 아직 모자라 `design:needs-research` 유지를 권한다 (출혈률 1차 숫자 없음).

## 반영안 (제안, 코드 미수정)

현재 값과의 차이: 문턱은 확인한 ATLS 표와 맞아 수정 불필요. 출혈률(mL/s)은 근거가 없는 추정 그대로이므로 지금 바꿀 근거가 없다. 다음을 제안한다.

1. 상수 구조: `RATES.blood.bleed` 표를 "기준 사망 시간(분)" 으로 적고 `bleed = deathLoss × blood ÷ (기준 사망 시간 × 60)` 로 계산하는 방식을 검토. 목표 시간이 이슈 수락 기준("동맥 사지는 분 단위, 경상은 시나리오 안에 안 죽음")과 직접 대응해 문서·그래프에서 설명하기 쉽다. 이름은 #29 규칙대로 `base…`(기준 사망 시간), 흔들림은 `varyCoef` 식으로 구분.
2. 문턱은 표에 ATLS class 와의 대응(III 시작=약해짐, IV 시작=실신)을 출처로 달아 `docs/calc/rates.md` 혈액 절에 적는다 (확인 등급은 리뷰 표 기준임을 표시).
3. 경상 0.5~1 mL/s 는 42~83분, 찰과는 6.9시간 만에 사망: "경상은 시나리오 안에 안 죽음" 기준(시나리오 길이는 수십 분~수 시간)에는 경상 0.5 가 겹칠 수 있어 경상 수치를 낮추거나 출혈 자연 멎음(응고)을 모델에 넣을지 결정 필요. 사용자 결정 사안.
4. 차트: `calc-charts.ts` 에 부위×정도별 혈액량-시간 선과 ±40% 띠, 30/40/50% 가로선을 더하고 `npm run charts`. 드릴(팔다리 경상·중상·치명, 복부 치명, 가슴 중상, 머리 치명)은 위 계산표의 시간 구간(±40% 폭)을 기대값으로 둔다. 확인장에는 혈액 막대+경과 시간 표시를 더한다.
5. 최소한 `팔다리 치명 12 mL/s` 와 `경상 0.5` 는 사용자가 목표 시간(추정)을 승인한 뒤 바꾼다. 승인 전에는 `추정` 표기를 `docs/calc/rates.md` 에 먼저 넣는 것이 안전하다.

### 판단

- 1차 자료가 받쳐 주는 것: 흉부 즉사는 심장·큰 혈관(흉부 치명상의 절반 남짓)이고, 폐 손상은 버티는 쪽이다. 따라서 "몸통 명중 = 항상 즉시 무력화"는 원문과 맞지 않는다. 부위 안의 장기별로 나누는 근거가 된다.
- 부상 뒤 무력화 **시간 분포**의 1차 수치는 아직 없다. Computer Man 의 시점(30초~24시간)이 시간 축의 틀로 쓸 만하다.
- 소총 몸통 명중도 "항상 즉시"는 아니라는 방향은 여러 2차 출처가 맞는다(권총 41%, 소총 80%대). 다만 부위별 결과 분포 표(수락 기준)로 쓸 만한 1차 자료는 아직 없다.
- 지연 무력화 시간은 "큰 혈관·장기 → 10~15초"가 유일한 숫자이고 법집행 기사라 `2차`.

- 주의: WDMET 원문은 "맞으면 거의 다 멈추고 쓰러진다"이다. 이는 수락 기준 1("몸통 피격 뒤 한동안 움직이고 쏨")과 긴장한다. 다만 멈춤·엎드림은 행동 선택(몸 낮춤)일 수 있고 의식·무력화와 다르다. 그래서 지연 창은 길게 잡을 근거가 없고, 짧게(수 초~수십 초) 잡는 것이 원문과 덜 어긋난다.
- 전투 중 "맞고도 계속 싸운" 비율, 무력화까지 시간 분포의 1차 수치는 이번에도 못 찾았다. 따라서 수락 기준 3("부위별 분포가 출처 표와 일치")을 채울 표는 만들 수 없고, 아래 값은 전부 추정이다.

### 현재 코드와 차이

- `body/wound.ts` `WOUND.bullet` (찰과·경상·중상·치명): 머리 [0,0,0.1,0.9], 몸통 [0,0,0.55,0.45], 복부 [0,0,0.6,0.4]. `isIncapacitated` 가 급소(`WOUND.vital`)의 중상 이상(level 2)을 즉시 무력화로 침. 머리 치명만 즉사(`isDead`).
- 출혈 `RATES.blood.bleed` 몸통 중상 6·치명 15 mL/s, 복부 5·12 (±40%), 실신 40%·사망 50% (5 L). 몸통 중상 6 mL/s 면 실신까지 약 5.5분이라 "치명 아닌 중상"의 출혈 지연은 이미 길다.
- 즉시 무력화가 출혈이 아니라 부위 규칙이라, 중상 몸통 병사가 실신 문턱 전까지 못 움직이는 것이 이슈의 문제.

### 반영안 (제안, 코드 미수정, 전부 추정 등급)

1. 몸통·복부 중상(severe)을 둘로 가른다: `WOUND.vitalSevere.delayedShare` (몸통 0.5, 복부 0.4) 만큼은 "기능 유지" 중상으로 굴린다. 근거: 흉부 치명상의 절반 남짓이 심장·큰 혈관(확인)이므로 나머지 절반은 폐 등 버티는 쪽. 복부 값은 근거 없는 추정.
2. 기능 유지 중상은 `Wound.incapTick = 맞은 tick + secToTicks(U[incapMin, incapMax])` 를 얻고, 그 전에는 `isIncapacitated` 가 이 상처를 무시한다. `incapMin`·`incapMax` 는 5 s·30 s (추정: 2차 10~15초 자료와 Computer Man 의 최소 5초 시점 사이). 그동안은 팔다리 기능 저하처럼 사격 산포·조준 계수(`WOUND.weak` 꼴)를 적용하는 `impaired` 단계를 둔다.
3. 머리 중상·치명은 지금처럼 즉시. 심장·척수(몸통 치명 0.45)도 즉시 유지. 난수 굴림이 하나 늘므로 `docs/calc/random/rolls.md` 갱신, 새 필드는 `docs/objects/soldier.md`.
4. 드릴: 몸통 피격 뒤 N 초는 움직임·사격이 되고 이후 쓰러짐 / 머리 피격은 즉시 / 같은 시드 `stateHash` 동일. 분포 시험은 시드 수천 회 돌려 `delayedShare` ± 허용 오차 안인지 확인 (표가 추정이므로 코드 상수와의 일치만 검증).
5. 반영 전 사용자 승인 필요: 위 값들이 모두 추정이라 research.md 규칙상 `확인`·승인된 `2차`가 아니면 코드에 못 넣는다.

### 5. 반영안 제안 (코드는 아직 안 바꿈. `확인` 부족 → 사용자 승인 필요)

수치는 근거가 약하므로 "적용 가능"이 아니라 후보와 필요한 결정이다.

- **A. 확인장 표시 수정 (근거 필요 없음, 먼저)**: 부상 줄의 `x.tick*DT` 를 "N초 전" 경과 시간으로 바꾸거나 둘 다 표기. 요청 외 UI 변경 예외(확인장 표시) 해당. 오독 재발 방지.
- **B. 급소 치명상 중 즉사 굴림 추가**: `rollWound` 에서 몸통 치명 총탄에 장기별 즉사 확률 `WOUND.instantDeath.torso`(가칭). 근거: 심장 열상 63 + 큰 혈관 37 = 흉부 치명상 절반+, 심장 손상은 대개 즉사(Sunshine, `확인`이나 이 세션 미재확인), 폐는 버팀. 확률값 자체는 `추정` (제안 시작점: 몸통 치명의 약 0.3~0.5, 복부는 낮게). 한 발 즉사 → 사용자 승인 후 사용. 난수 순서가 바뀌므로 `docs/calc/random/rolls.md` 갱신 필요.
- **C. 몸통 치명 출혈률 상향 대안**: 12~15 → 수십 mL/s (예: 30 mL/s ≈ 1.4분에 50%). 한 발에 수십 초~분 단위로 죽게 됨. 폐·간까지 뭉쳐서 더 높이는 부작용. 근거는 `추정`.
- **D. 누적 외상 사망 문턱**: "몸통 급소 중상 이상 부상 N개 이상이면 사망" 같은 규칙. 문헌 수치 없음(Bellamy: 미해결) → 순수 설계 결정. N 은 `추정`. 이슈 사례(9 치명)는 B(굴림)로도 거의 확실히 사망하므로 D 없이 B 로 충분할 수 있음: 치명 9발에서 즉사 확률 p 이면 생존 (1−p)^9, p = 0.3 이면 4%.
- **E. 문턱(30/40/50%)**: ATLS 분류와 방향이 맞으므로 유지 권장 (`2차`, 표 원문 미확인).
- 수락 기준의 드릴 3종(치명 1발 / 몸통 연발 1·5·15초 / 사지 단독이 빨리 안 죽음)은 B 또는 C 선택 후 기대값이 정해져야 쓸 수 있음. 지금은 기대값(1초 시점 사망 여부 등)을 받칠 `확인` 수치가 없다.
- 사용자 결정 필요: (1) 즉사 굴림(B)을 쓸지, 출혈 상향(C)을 쓸지, (2) 확률·임계값을 `추정` 그대로 쓸지.
