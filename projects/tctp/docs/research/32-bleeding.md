# #32 출혈·사망 시간

조사일 2026-10-16. 지금: 부위×정도 출혈 mL/초 ±40%, 약해짐 30%·실신 40%·사망 50% (혈액 5 L).

## 확인

없음. 이 조사에서는 원문 쪽수를 붙여 읽은 출혈 수치를 얻지 못했다.

## 2차

| 항목 | 값 | 출처 |
|---|---|---|
| 대퇴동맥 출혈은 수초~수십 초 안에 치명 | 정성 서술, 숫자 약함 | [JSOM Spring 2016 p.66](https://www.jsomonline.com/Flipbook/Journals/1601-Spring/files/basic-html/page66.html) |
| 서혜부 지혈은 54초 넘으면 너무 느림, 지혈 장비 적용 29~37초 | 접합부 출혈 장비 시험 | 같은 곳 |
| 대량 출혈 사망 60~120초 | 해병 교육 자료 | [FMTBE 402](https://www.trngcmd.marines.mil/Portals/207/Docs/FMTBE/Student%20Materials/FMST/402.pdf) — 원문 쪽수 못 열음 |
| 지혈대: 1분 안에 지혈, 3분 안에 고정, 2시간 미만 안전 | TCCC 교육 모듈 | [TCCC 모듈 6](https://tccc.org.ua/files/downloads/module-06-massive-hemorrhage-control-in-tfc.pdf) |
| 출혈 1등급 15%(≈750 mL) | ATLS 분류 (II 15~30 · III 30~40 · IV 40 초과는 기억 값, 확인 안 함) | 요약 |
| 전장 사망: 지혈대 보급 뒤 사지 출혈 예방 가능 사망 7.8% → 2.6% | | Eastridge 외, *J Trauma Acute Care Surg* 2012;73(6S5):S431 — 본문 못 열음 |

## 판단

- 코드의 문턱(30·40·50%)은 ATLS 분류와 방향이 맞다. 그러나 **부위·정도별 mL/초**를 받치는 숫자는 없다. 절대 속도보다 "사망까지 몇 분"을 목표로 두고 거꾸로 맞추는 쪽이 낫다(동맥 사지 수 분, 몸통은 수 분~수십 분).
- 근거가 모자라 `design:needs-research` 유지.
