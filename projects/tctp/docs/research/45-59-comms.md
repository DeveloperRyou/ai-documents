# #45·#59 음성·수신호·무전 전달

조사일 2026-10-16.

## 확인

| 항목 | 값 | 출처 |
|---|---|---|
| 지휘 통제 수단 | 음성, 수신호(손·팔), 신호탄 등 시각 신호, 무전. 사격 통제용 손·팔 신호 그림이 있고 설명은 FM 21-60에 있음 | FM 3-21.8(2007) 2-119, 부록 A-95 |
| 수신호는 보여야 쓴다 | 사수가 지휘관을 볼 수 있을 때 유효한 사격 통제 수단 | 같은 곳 A-95 |
| 야간·시계 불량 | 병사 사이 간격을 줄여 서로를 보게 함 | 같은 곳 |

## 못 찾음

- 음성이 닿는 거리(m), 총성 속에서 줄어드는 정도: 이 교범 본문에 수치 없음.
- 무전·휴대 무전기 도달 거리와 지연: 교범에서 분류만 나옴(SINCGARS급). 기종별 거리는 제원서가 필요.
- 수신 지연 시간: 출처 없음 → 전부 `추정` 후보.

## 다음에 볼 곳

- FM 21-60 *Visual Signals*, FM 6-02.53 *Tactical Radio Operations* (AN/PRC-148·152 도달 거리), 소음과 음성 명료도 연구(ANSI S3.5 Speech Intelligibility, 야전 음성 도달 거리 보고서)
- 총성 소음 레벨: MIL-STD-1474
