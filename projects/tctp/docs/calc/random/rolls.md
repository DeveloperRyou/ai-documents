# 난수를 쓰는 곳 (굴림 목록)

[../README.md](../README.md) "한 틱 순서" 대로 적는다. 같은 단계 안은 병사 id 순. 흐름은 따로 적지 않으면 `World.rng`.
분포 이름(`vary`, `gauss`, `inDisk` …)은 [README.md](README.md). 상수는 `VARY`([`core/vary.ts`](../../../packages/sim/src/core/vary.ts))와 각 파일의 튜닝 상수.

## 흔들림 상수 `VARY` ([`core/vary.ts`](../../../packages/sim/src/core/vary.ts))

| 상수 | 값 | 뜻 |
|---|---|---|
| `reaction` | 0.5 초 | 명령을 알아듣고 움직이기까지 0 ~ 이 값 |
| `pace` | ± 10% | 이동 행동 하나의 걸음 빠르기 |
| `stride` | ± 5% | 틱마다 걸음 |
| `dest` | 반경 1 m | 같은 지점 명령에 각자 서는 자리 (명령 순서로 정한 자리 `slotOffset` 에 더함). 대형 이동은 무리를 열 때 병사마다 한 번 굴려 도착 자리에 더한다 (`openGroup`, 경로 `planRoute` 굴림 뒤) |
| `aim` | ± 25% | 점사마다 조준 시간 |
| `burst` | ± 1 발 | 점사 발 수 (점사 2발 이상 화기만) |
| `hold` | 산포 × 0.5 | 점사마다 겨눔 어긋남 표준편차 (화기 산포 대비) |
| `reload` | ± 20% | 재장전 시간 |

몸 수치의 흔들림(`RATES.*.vary`)은 [../rates.md](../rates.md).

## 1. 명령 ([`command/command.ts`](../../../packages/sim/src/command/command.ts))

| 굴림 | 분포 | 결과 |
|---|---|---|
| 반응 시간 | `int(0, round(0.5 × 4))` = 0·1·2 틱 균등 | 0 이면 바로 따름. 혼란·위축이면 + 8틱(`STRESS.orderDelay` 2초, 굴리지 않음) |
| 서는 자리 (`move`) | `inDisk(1 m)` | 목표 = 명령 지점 + 어긋남 |
| 경로 휘기 (`move`) | `gauss` (±2σ 로 자름) × `PATH.meander` | 곧은 구간 20m 마다 나눈 점 하나당 한 번, 서는 자리 다음 걸음 빠르기 앞 ([../movement.md](../movement.md) "경로 탐색") |
| 걸음 빠르기 (`move`) | `vary(1, ±10%)` | 행동의 `pace`, 도착할 때까지 그대로 |
| 재장전 시간 (`reload` 명령, 사격 중 탄창 빔) | `vary(화기 기준 재장전 시간 reload × 팔 계수, ±20%)` → `secToTicks` | 행동의 `until` |

- 반응 시간 굴림은 명령을 받는 병사마다 (무력화·패닉이면 굴리지 않음). 명령 적용 시점에 굴리고, 미뤄 둔 명령이 적용될 때는 다시 굴리지 않는다.

## 2. 행동 ([`command/action.ts`](../../../packages/sim/src/command/action.ts), [`combat/fire.ts`](../../../packages/sim/src/combat/fire.ts))

### 이동
| 굴림 | 분포 | 언제 |
|---|---|---|
| 걸음 흔들림 | `vary(1, ±5%)` | 도착하지 않은 이동 행동마다 매 틱 (막혀 못 가도 굴림) |

### 줍기 (#8)
| 굴림 | 분포 | 언제 |
|---|---|---|
| 줍는 시간 | `vary(3초 + 1초/kg × 가져오는 무게, ±20%)` → `secToTicks` | 곁에 닿은 틱 (닿았다가 멀어지면 다시 정함) |
| 걸음 흔들림 | `vary(1, ±5%)` | 곁에 닿기 전 걷는 틱마다 |

### 건네기 (#38)
| 굴림 | 분포 | 언제 |
|---|---|---|
| 건네는 시간 | `vary(3초 + 1초/kg × 건네는 무게, ±20%)` → `secToTicks` | 곁에 닿아 건네기를 시작하는 틱 |
| 걸음 흔들림 | `vary(1, ±5%)` | 곁에 닿기 전 걷는 틱마다 |

(보급소 줍기는 줍기 (#8) 와 같은 굴림.)

### 사격 — 점사 하나에
| 굴림 | 분포 | 결과 |
|---|---|---|
| 조준 시간 | `vary(aim × slow, ±25%)` × 4 → 반올림 | 조준할 틱 수 `need` (점사 시작 때 한 번) |
| 점사 발 수 | `int(−1, 1)` 더함 (최소 1) | 화기 `burst` > 1 일 때만 굴림 |
| 쓸어 쏘는 자리 | `inDisk(반경)` (줄이면 먼저 `next()` 하나로 선 위치 t) | 제압사격은 아는 접촉으로 정한 영역 ([fire.md](../fire.md) §2a), 조준사격은 `inDisk(0)` (굴리긴 함) |
| 겨눔 어긋남 | `gauss` × 2 (x, y), 표준편차 `0.5 × dispersion/1000 × 거리` | 점사 안 탄이 함께 쏠림 |

### 사격 — 한 발에 (`pullTrigger`)
| 굴림 | 분포 | 결과 |
|---|---|---|
| 직사 방향 | `gauss` × σ (방위각), `gauss` × σ (앙각) | 탄도선 ([../fire.md](../fire.md) "산포") |
| 지물이 탄을 멈춤 | 지물 높이 안 0.5 m 마다 `chance(1 − exp(−밀도 × 0.25))` | 탄도선 검사가 처음 성공한 곳에서 탄착. 지물이 없는 칸은 굴리지 않음 |
| 곡사 탄착 | `gauss` × σ × 거리 (x), (y) | 탄착점 |
| (맞으면) 부상 | 아래 "부상" | |
| 근탄 스트레스 | 사람마다 `vary(15 × 몰아쏘기, ±30%)` × scale | 제압 반경 안 사람 (id 순) |

### 수류탄 던지기 ([`combat/grenade.ts`](../../../packages/sim/src/combat/grenade.ts))
| 굴림 | 분포 | 결과 |
|---|---|---|
| 준비 시간 (던지기 첫 틱) | `vary(기준 준비 시간 × 계수, ±25%)` → `secToTicks` | 행동의 `until` |
| 던진 자리 | `gauss` × σ (x), `gauss` × σ (y) — 던지는 틱에 이 순서 | 산포 ([../fire.md](../fire.md) §5a) |
| 신관 | `int(secToTicks(fuseMin), secToTicks(fuseMax))` — 위 두 굴림 다음 | `LiveGrenade.explodeTick` |

터질 때는 아래 `explode` 굴림.

### 부상 (`wound` → `rollWound`, `shock`)
| 순서 | 굴림 | 분포 |
|---|---|---|
| 1 | 정도 | `u^(50/위력)` 를 누적표 `WOUND.bullet`·`fragment` 에 ([README.md](README.md) "치우침") |
| 2 | 출혈 속도 | `vary(baseBleed(부위, 정도), ±40%)` (기준 사망 시간에서 셈, [rates.md](../rates.md)) |
| 2½ | 즉사 | 총탄 가슴·복부 치명일 때만 `chance(가슴 0.4 · 복부 0.25)` → `Wound.fatal` (조건이 정도로 정해져 결정적) |
| 3 | 피격 스트레스 | `vary(30, ±30%)` |
| 4 | 쇼크 (바로 패닉) | `chance(찰과 0.02 · 경상 0.1 · 중상 0.6 · 치명 0.9)` |

## 3. 몸 (`updateBody`, 죽지 않은 병사마다)

| 굴림 | 분포 | 언제 |
|---|---|---|
| 지구력 | 움직이면 `vary(소모, ±20%)` × dt, 멈추면 회복 시간 `dt × vary(1, ±20%)` (숨참·피로 지수 감소에 같이 씀) | 매 틱 |
| 전우 피격 스트레스 | 곁 15 m 안 전우마다 `vary(15, ±30%)` | 이 틱에 막 무력화된 병사가 있을 때 |
| 패닉에 빠짐 | `chance(perSecChance(0.2 × (스트레스 − 70)/30))` | 제압 단계일 때 매 틱 |
| 스트레스 회복량 | `vary(회복 속도, ±50%)` × dt | 마지막 위협 뒤 4초가 지났고 스트레스 > 0 |
| 패닉에서 벗어남 | `chance(perSecChance(0.25))` | 패닉이고 스트레스 < 30 |

## 4. 경계 시선 ([`perception/scan.ts`](../../../packages/sim/src/perception/scan.ts), `World.lookRng`)

무력화된 병사, 사격·이동사격 중인 병사(눈이 겨누는 쪽에 고정)는 굴리지 않는다.

| 굴림 | 분포 | 언제 |
|---|---|---|
| 돌아볼 반응 시간 | 0.3 ~ 1 초 균등 → `secToTicks` (1 ~ 4틱) | 이 틱에 위협을 받았고, 적 직사 탄이 이 틱에 있었으며, 돌아볼 예정이 없을 때 |
| 소리로 어림한 방향 | 가장 가까이 지난 탄의 쏜 쪽 + `gauss` × 25° | 같은 때 |
| 들은 소리를 돌아볼지 (#35) | `chance(소리 크기)` | 이 틱에 적 소리를 들었고 돌아볼 예정이 없을 때 (위 근탄 돌아보기가 먼저) |
| 들은 소리 반응 시간 | 0.3 ~ 1 초 균등 → `secToTicks` | 돌아보기로 했을 때 |
| 들은 소리 방향 | 가장 큰 적 소리 쪽(총구·폭발점) + `gauss` × 25° × (1 + 2 × (1 − 크기)) | 같은 때 |
| 적 쪽을 볼지 | `chance(0.85)` | 볼 곳을 고를 때 (아는 적이 있을 때만) |
| 적 쪽 흔들림 | ± 15° 균등 | 적 쪽을 볼 때 |
| 후방이 앞을 볼지 | `chance(0.4)` 면 뒤, 아니면 정면 | 분대 맨 뒤 병사가 구역 안을 볼 때 |
| 구역 안 다음 곳 | 지금 자리 ± 35° 균등, 구역 ± 50° 로 자름 | 구역 안을 볼 때 |
| 한 곳 보는 시간 | 1.5초 × (1 ± 60%) → `secToTicks` (2 ~ 10틱) | 볼 곳을 고를 때마다 |

혼자인 병사(분대원 1명)는 정면만 보고 굴리지 않는다 (돌아보기는 굴림).

## 4-1. 기본 상태 ([`body/soldier.ts`](../../../packages/sim/src/body/soldier.ts) `updateBaseState`, `World.stateRng`)

`updateBody` 끝에서 병사 id 순으로. 무력화·사망 병사는 굴리지 않는다.

| 굴림 | 분포 | 언제 |
|---|---|---|

## 4-2. 패닉 결과 ([`body/panic.ts`](../../../packages/sim/src/body/panic.ts) `choosePanic`, `World.stateRng`)

병사가 패닉에 빠진 틱, `updateBody` 안에서 병사 id 순으로 한 번. 엄폐 속이거나 아는 적이 없으면 굴리지 않는다.

| 굴림 | 분포 | 언제 |
|---|---|---|
| 항복할지 | `chance(0.4)` | 아는 적이 15m 안일 때 |
| 도주할지 | `chance(0.6)` | 항복이 아니었고 아는 적이 100m 안일 때 |

## 5. 탐지 (`updateVision`, 매 틱, `World.searchRng`)

발견 굴림은 전용 `searchRng` 로만 한다 (사격·시선 난수 흐름과 분리, #33). 굴림은 **조건이 바뀔 때만** 일어난다 — 매 틱 굴리지 않는다.

| 굴림 | 분포 | 언제 |
|---|---|---|
| 끝내 찾는가 | `next() < P∞` | 병사 id 순으로 각자, 적 병사 id 순. 아직 못 본 적이 시선에 들어 있고 탐색 계획이 없거나 x 가 계획을 굴린 때보다 `rerollOctaves` 이상 바뀌었을 때. P∞ = 0 이면 굴리지 않음 (난수를 쓰지 않는다) |
| 발견까지 시간 | 지수 분포: `−τ · ln(1 − next())` 초 (시야각 안에서 흐름) | 위에서 "찾는다"가 나왔을 때 곧바로 (난수 1개) |
| 보고 위치 오차 | `inDisk(posError)`: 반지름 √난수, 각도 난수 (난수 2개) | 보고를 예약할 때마다 (`sendReport`), 받는 병사 id 순 (본 틱에 병사 id 순 안에서) |

이미 보던 적이 시선 투과 0.15 이상으로 남아 있으면 굴리지 않는다. 발견 조건 x·P∞·τ 식은 [../vision.md](../vision.md) 3절. 계획(`World.search`)·사격 단서(`World.cue`)는 `stateHash` 에 들어간다.

## 결정성 체크리스트 (굴림을 더하거나 고칠 때)

- `World.rng` / `lookRng` / `stateRng` / `searchRng` 만 쓴다. 새 쓰임새가 다른 결과를 흔들면 안 되면 흐름을 나눈다 (`lookRng`·`stateRng` 처럼).
- 조건부로 굴리면 (예: 확률이 0 이면 안 굴림) 조건도 결정적이어야 한다.
- 굴리는 순서를 바꾸면 같은 시드 결과가 바뀐다 → 시드에 기댄 드릴·테스트 기대값을 다시 확인한다.
- 새 상태 필드는 `stateHash` 에 넣는다.
- 이 표와 [../README.md](../README.md) "한 틱 순서" 를 함께 고친다.
